\# Smart Parking Management System



A full-stack, real-time parking management application that connects an interactive dashboard with a reliable backend and database, enabling efficient tracking of parking occupancy and vehicle movements.



\## Tech Stack



Backend:

\- ASP.NET Core Web API

\- C#

\- SQL Server

\- RESTful API

\- Clean Architecture principles



Frontend:

\- Next.js

\- React

\- Tailwind CSS



\## Key Features



\- Real-time visual parking grid

\- Live availability and occupancy status

\- Instant statistics for total, available, and occupied spots

\- Vehicle check-in / check-out management

\- Seamless synchronization between frontend and backend

\- Persistent data management using SQL Server



\## Project Structure



project/

\- SmartParkingApi/ (Backend - ASP.NET Core Web API)

\- smart-parking-dashboard/ (Frontend - Next.js Dashboard)



\## What I Learned



Building this project provided hands-on experience with full-stack architecture, REST API development and integration, state management, database design, backend-frontend communication, and building responsive, real-time dashboards.
